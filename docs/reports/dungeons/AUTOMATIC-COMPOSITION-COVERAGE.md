# Automatic composition and placement coverage

This offline audit joins native directed physical room candidates to reviewed guide quantities and native species identities. It does not activate configurations or prove official encounter quantities.

Eight candidates pass identity and actual combat formation checks. Three additional geometrically valid placements were rejected because reviewed guide species remained unresolved. These three must not become runtime configurations.

Run `PYTHONPATH=server python server/tools/audit_dungeon_flow_compositions.py --validate-placement` with catalog access. The placement step uses the existing published combat geometry and enemy formation implementation; exploration retains its separate native 6/0/4 profile.

See [native flow coverage](AUTOMATIC-NATIVE-FLOW-COVERAGE.md), [master inventory](INVENTORY.md), and [structured audit](AUTOMATIC-COMPOSITION-COVERAGE.json).

Prepared candidates are explicit DEV compositions, preserving reviewed quantities where present. Boss identities come from reviewed guide roles, singleton native ultimate definitions, or the previously reviewed Tofu identity. No name matching or level sorting decides which species is a boss.

Every candidate requires native exit-object binding and special-mechanic review before runtime activation. Transport, mixed transport/physical, branched and unexplained open geometry are withheld. Boss-specific spells, phases and rewards are outside this geometry/composition proof.

Boss readiness audit: [native ability coverage](AUTOMATIC-BOSS-ABILITY-COVERAGE.md). All eleven initially audited bosses have incomplete owned spell coverage; formation success does not imply complete boss behavior.
