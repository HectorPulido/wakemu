# Open family arena preparation

These ordinary classic definitions have a native reachable component without
proved separators. Under explicit user authorization, this preparation uses one
local encounter containing eight family actors, with each identified boss once.
It does not claim to reproduce official preliminary rooms or official counts.

Boss identity comes from `REMAINING-FAMILY-BOSSES-20261010.json`. Theatre
Intemporal has an empty installed dungeon pool: the independently reviewed web
roster supplies exact names, joined to installed family 1150 and native BOSS
property 43. Its selected references are 5715, 5716, 5717 and boss 5718.

Validation preserves native arrival, directed exploration reachability, a native
exterior exit, engagement reachability and complete combat formation including
six player positions. Unproved internal teleports are rejected. Configuration
plan hashes are rebuilt after attaching the family evidence. No runtime import,
activation, server restart or client modification is performed by this tool.

The two inactive Tower Mineral level variants are included as separate native
definitions; they are not additional distinct dungeon names.

Machine-readable results and exact block reasons are in
`FAMILY-OPEN-CANDIDATES-20261010.json`. Generated configurations are under
`.runtime/local/family-open-candidates-20261010/`.

Reproduce from the repository root using the normal read-only published catalog
connection:

```sh
PYTHONPATH=server python server/tools/prepare_family_open_dungeons.py
```

Boss mechanics are not certified by route or formation validation.
