## Reuse and authority

`combat_characteristic_swap.py` expresses the ordered setter primitive without approximating PA ownership. `combat_characteristic_swap_handler.py` integrates native event phases, UID, captured payload, owned retention, notification and removal. Capture occurs after phase2 subscribers, not during operand preparation.

Ordinary PA support requires actual characteristic metadata, nonexpandable and non-overmax PA, exact hard bounds and an unfrozen current. These establish that the represented current is the raw setter current. Unknown hidden raw values reject before any PA mutation. Copied PA uses the existing source-qualified raw-current/setter implementation, including native frozen behavior. Shift arithmetic uses signed Java integer wrapping and native bounds checks. This does not fabricate support for arbitrary HP/resource PA sources.
