## Native probability and selected local balance

The installed native client computes:

```
B = min(floor(profession_level / levels_per_point), maximum_level_bonus)
    + authoritative_effect_bonus
p = clamp((native_soil_threshold / 100) * climate_factor
          * (1 + float32(float32(B) / float32(100))), 0, 1)
display = -1 if p <= 0 else floor(100 * p + 0.5)
```

Migration122 supplies a configurable local policy with `levels_per_point=2` and `maximum_level_bonus=100`. This is an emulator balance choice, not an official level bonus. Profession levels come from account-owned SQL XP. The zero-threshold soil remains forbidden regardless of level. Climate factor is1 when absent/unrestricted/compatible, otherwise0.8. Bonus scope is profession, not individual seed difficulty. Additional bonuses require an authoritative effect provider; none are invented from equipment or client input.

The intermediate float32 division matters: threshold50 and bonus1 produce probability0.5049999998882413, whose native display is50, not51. `VerifyNativePlantingPolicy.java` and its Python comparison cover60,802 combinations of all integer soils0..100, integer bonuses−100..200 and both climate states. Luna confirmed the exact probability and displayed-percent matrix passes.

## Why the open profile cannot display arbitrary percentages

`OpenPlantingAgent` replaces the entire native `dev.am` body with `return1` when `wakfu.local.openPlanting=true`; it also replaces `ffY.C` with100. No weather packet, actor bonus, family population or server probability can affect that intercepted display. `open_planting_probability` controls the real SQL transaction chance, independently of this fixed display.

The existing Mac local launcher can disable this override without changing client source or assets. Proposed manual launch, not executed here:

```sh
env -u WAKFU_LAUNCHER_CONFIG WAKFU_OPEN_PLANTING=false bash client-tools/local-client.sh --profile planting-native-qa
```

The configured/portable launcher instead reads its existing `open_planting` boolean; the environment command above is specifically for the Mac local-launcher path. Server native profile also requires `WAKFU_OPEN_PLANTING=0`; that is a deployment configuration change and was not performed. Native terrain, family and profession restrictions then apply.
