# Protector identity and dialogue frontier

This is one new bounded join across existing native exports, after Otomai's
protector identity exposed the limits of a conversational-breed-only inventory.
It does not repeat Lua, map POI or complete capture-directory scans. No server,
client, service, runtime database or catalog enablement was changed.
