# Missing runner families 308 and 325

## Family 308 — eYW

This is a subclass of the configured area creator eYQ. Its application calls
the parent first and then fQG on the newly created faV. If caster or area is
absent, or the area lacks sgQ, the hook returns. Otherwise it adds the caster
sgQ current value when present. If the area has sgP, it adds caster sgP and
then caster sgS to that same PA when present.

The fbo.rNy area-property branch copies sgR, sgS, sgU, sgT, shY, shX, shV and
shW through faV.a(PC,PV). That helper requires both characteristics to exist,
resets the area's PA via aYY and then adds the caster's current value via nG.
Without that property, actual PL kind11 is cast to fyG and the spell's native
element selects eVg.fLC; a present caster characteristic is added to area sgQ.

This cannot be implemented as an alias of area creation: the current generic
area rows lack source-authoritative constructor/current PA maps. faW and fbd
constructor subsets do not establish the full faV damage-characteristic map.
No speculative map or setter has been added, and family308 is not registered.

0. Application invokes eGj.lx(aSg==1) only for a non-null eGj target; otherwise
it is a no-op. lx delegates to the actual eGZ component. Removal invokes lx
with the target's class-defined dpR baseline before parent removal. It does
not restore the value preceding the effect. bbz and actor-owner bbA are true;
cell-owner bbB is false. No execution-status setter appears in this runner,
so the original fresh -1 status is retained.

The shared producer and callback handler use the existing typed
native_controlled_by_ai field and require an independently proved dpR
baseline for restoration. Six pure tests pass, including preparation before
application, phase order, constructor status and packet preflight before
mutation. Original Java eYH.C passes five signed-int parameter cases. These
callback tests do not certify production factory delivery. The factory now
registers this runner only for a supplied complete actual execution-context
payload; absent normal fresh context remains rejected before UID allocation.
The central retained ownership path records the runner under its actual
manager and removal restores the separately proved dpR baseline. A retained
application/removal regression verifies cvX/12613 followed by cvZ/13560 and
the actual control-field mutation. Runtime factory audit remains delegated
to the validation agent.
