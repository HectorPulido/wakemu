## General preparation policy for the normal bulk audit

1. Construct the actual class/level/deck and selected native arena, install snapshots, then execute production Ready and opening delivery. Record the actual owned book, complete PB/characteristic snapshots and state ledgers. This is the no-extra-preparation baseline; its facts are authoritative, not an empty context dictionary.
2. Evaluate each criterion against the actual caster and selected target/cell. Record true, false or missing authority separately. A false state-dependent branch is a legitimate guarded result; an unknown provider cannot become false. Retain the selected native table and all changed range/cost/LOS/cell flags.
3. For state-dependent branches, obtain candidate callers from the matrix, select only actually owned/legal actions, and execute them through ordinary transactions. Check the resulting ledger, source ownership, level threshold and duration. A candidate whose own criterion is false remains guarded; do not force its effect reference or install a state to reach the desired branch.
4. For book/grant, summon/morph and carrying predicates, use their distinct real producers. Deck membership differs from GetSpellLevel; static307 creation differs from captured/copied descriptors; original controller differs from current master; physical carrying differs from summon ownership. Null cell-target PV differs from an unknown non-null actor ID.
5. Run the same original request on the prepared committed fight and compare selected table, client inputs, actual permission, costs, effects and retained reactions. Exercise the source's ordinary removal/expiry and repeat. Classify an unavailable producer as a preparation gap, preserving its native dependency rather than inventing an alternative scenario.
