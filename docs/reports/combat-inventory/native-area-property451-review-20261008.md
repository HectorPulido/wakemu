# Native area property family451

Original `eWs.c` requires a Qq target and a valid `fbo.Tn` lookup. Null,
fighter and unknown-property targets mark native execution unsuccessful and do
not mutate properties. A valid target receives `PV.f(PE)`; `bbR` calls
`PV.h(PE)`. `faV` implements these calls using its `rzt` set. They are not
fighter PB counters: duplicate applications remain one member, and the first
removal deletes that member even if another runner is retained. Removing a
property originally present on the prototype also deletes it; there is no
restore-to-baseline or reference-count behavior.

The shared handler now registers family451 in the runtime factory, keeps exact
retained runner identity/timer/state ownership, and routes removal through the
existing atomic stat-effect lifecycle. Actual active or retained area objects
receive a checkpoint-safe current property set with explicit source metadata.
Area activation and registered property authority read the current set instead
of only the static prototype. Fighter targets follow native unsuccessful
execution, rather than receiving an invented property effect.

contains no branches for those node IDs. Native probe uses the original eWs
