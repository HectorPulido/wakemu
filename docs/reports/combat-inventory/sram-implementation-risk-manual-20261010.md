## Manual battery after automated runtime verification

Use a normally prepared level200 Sram, an enemy that survives several attacks,
and one ally observing the same fight. Do not inject states, resources, summon
properties or trapped coordinates. Repeat each branch in a fresh encounter when
resources or per-turn limits require it. Record both clients and corresponding
server cast diagnostics. This battery is pending execution, not a deployment claim.

1. Equip each normal active spell in legal deck batches and cast every spell
   listed in `sram-code-inventory-20261010.md` once on its allowed target. Compare
   tooltip cost/range/LOS, actual AP/MP/WP changes, target damage/healing and state
   levels. Include frontal and rear targets with the same native orientation.
2. Use the actual Ready-granted Invisibilidad4604. Have the enemy observer verify
   concealment while the Sram owner retains control. Move, attack, finish the
   turn and advance through normal turn/ACK flow. Check detection/reveal and
   removal against the selected native branch; absence of a visible owner sprite
   alone is not proof of enemy targeting secrecy.
3. Use actual Ready-granted Doble4603 on a free adjacent cell. Confirm one actor,
   source-derived HP/characteristics, controller and four owned actions
   4612/8480/4611/8502. Advance real turns, use permitted Double actions, then kill
   the Double normally. Check timeline removal, ownership cleanup, footprint
   release and a legal later resummon.
4. Cast each granted trap5182/5183/5184, then the passive-enabled alternatives
   8505/8506/8507 in separate legal builds. Move the appropriate actor onto the
   actual trap using normal movement. Check source-derived activation eligibility,
   displacement/teleport, damage and activation exhaustion. Use Quitar una
   Trampa5186 and verify removal/footprint reuse. Check an unrelated enemy trap
   is never removed as if it belonged to the Sram.
5. Repeat positional/resource attacks after their real producer actions. Compare
   state source, level and consumption before/after; crossing a source threshold
   must change the selected branch without manual state installation. Repeat
   with each of the15 legal passives and its advertised trigger, distinguishing
   passive installation from actual reaction.
6. Reconnect during concealment, with a live Double and with an active trap.
   Confirm the complete actor roster, timeline membership, area lifetime and
   subsequent legal actions survive. Capture any explicit missing authority;
   do not treat an exception or silently absent child as successful recovery.
