# Native microbot area registration

The remaining family339 rejection for faW kind4 was labelled a timeline gap.
Original `fcb.f(Qq)` actually registers the area's QI obstacle when applicable,
then calls `fdp.b(faW)` for kind4: this is a microbot rail network, separate from
fighter turns. `fcb.g(Qq)` removes its QI registration before `fdp.c(faW)`.

`fdp` keeps one owner network keyed by actual `faW.dTD()`. On its first creation
it captures the owner's `ffw.shM` characteristic, ID93; native absence defaults
to3. The implemented fighter producer requires a known characteristic93 rather
than treating missing Python data as proven native absence. Empty networks
remain installed and keep their captured distance after the last area removal.

`fdq.j` groups registered microbots by X and by Y using fresh default
TIntObjectHashMaps. Their int hash returns the signed operand; it differs from
the long hash for negative keys. Groups use original `fdr`/`ayJ` comparator
and binary-search insertion order. Consecutive aligned positions link when
`aBn.B` (Manhattan distance minus1, with a minimum0) is within captured range
and original Sn accepts the path. Contiguous links merge through `fdl` endpoint
extension. The network stores ordered segments and inclusive cell membership;
the stored cell order is not presented as original Java HashSet iteration.

The path projection uses actual published terrain columns with Sn configuration
height6/radius1/jump4. Original `Sn.c` invokes its query with optionFalse, so its
QI.Z branch is skipped. Physical columns come from inherited VE.aO/VB.a; QI
does not override that source. Cell altitudes come from actual QI.X. The pure
projection avoids leaking temporary QI.bf flags into other queries.

The area handler now preflights that authority, creates its normal faW record,
registers the owner network and keeps the original Qf and area callback path.
It creates neither fighter HP nor roster membership. Removal updates network
membership at the actual area removal boundary. All new checkpoint data is
plain dictionaries, integers and lists. Client area application continues using
the existing native constructor packet; this change does not invent a separate
rail notification packet or claim an original fdn wire producer.

Validation prepared: six focused tests, including actual prototype978 through
the area handler and Qf/removal; a100-trial original Java fdq/prototype978
differential checks ordered segments, negative coordinates and rehashes. The
actual family339 cast audit remains required before declaring this gap closed.
