# Closest specific area distance

Original lexer token112 resolves to `eJT extends eIw`. Its numeric signature is `(string selector, long reference, boolean pathMode[, string ownerSelector])`. `eJT.d` returns the minimum surviving distance, or long-1 if its input list is null/empty.

`eIw.j` evaluates reference and path boolean, then resolves its main selector through case-sensitive `ePF.tw` and requires an actual eGj. Null or a nonfighter eHg returns a null distance list before resolving the fight or optional owner. A required fight missing for an actual eGj throws. The active complete `Qs.bdm` population is filtered by exact Qq.bct prototype reference and optional direct owner. A null optional owner means all owners; a non-null owner must match the actual Qq.bch identity, not a controller-chain root or team.

With pathMode=false it calls selected eHg.baM().A(area.baM()), exact XY Manhattan distance with Java signed-int subtraction/absolute/addition. It ignores height and physical-radius subtraction. With pathMode=true it configures Sn using actual selected actor bcK/bcL/bvz and QI, source position, Sp.bpz=400/bpy=256/bpA=false, then reads Sn.bgn for each actual area destination. It does not substitute Manhattan distance for a missing path result.

Every mapped distance≤0 is filtered out. In particular, an area on the selected actor's cell is excluded. The nearest strictly positive result is returned, or-1. The caller's numeric comparison receives that actual-1 unchanged, even when the surrounding content expression consequently evaluates true.

`closest_specific_area_distance` now shares the registered `_rows` population and faN owner-following geometry. It supports exact geometric distances generally, and path distances only through an explicit authoritative callback. Null/nonfighter selected recipients and empty matching populations preserve native-1. Missing non-null actors or needed path authority reject. The condition callback integrates the proven main caster/target forms, numeric reference expressions, boolean expressions and optional actual owner relationship; native event-selector contexts remain explicit unknowns until their payload authority is present.
