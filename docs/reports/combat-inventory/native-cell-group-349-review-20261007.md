# Native cell group 349

The installed registry maps family 349 to `eYk`, extending `eXR` and `eYg`. This runner executes the full child iterator once for each selected cell; parameter zero limits cells, not successful effects. Child calls supply actual QI-selected height, null PV, and a fresh `eVt.a(false, false, triggeringRunner)` context. The parent container supplies the level unless its actual transmission flag sets the short-valued override. Native cell order is preserved until the optional shuffle and sort.

Paired parameters are evaluated at the actual container level. Parameter 1 selects raw actor/cell ownership in `eXR`; parameter 2 enables per-cell criterion filtering and bypasses the outer runner criterion. Parameters 3 and 4 select orientation toward the original anchor and centering on the caster. Parameter 5 is stored but not consumed by the native population or dispatch methods. Parameter 6 controls shuffle and defaults to enabled when absent. Parameter 7 selects Manhattan-distance/angle spiral order, reverse order, or stable unchanged order for an unknown enum.

The area producer uses the actual native QI rectangle, masks, and indexed surface columns. An EMPTY (`anA`) area means the cached QI whole-map population in this runner. Its unfiltered/null-criterion branch preserves cells with absent selected heights, unlike ordinary areas and the filtered non-null-criterion whole-map branch. Movement walkability is not a substitute for these facts. A coincident anchor with orientation-toward-anchor can supply a null native direction; the implementation rejects that unsupported geometry rather than inventing a facing.

`server/protocol/native-class-cell-group-metadata.json` contains the 36 actual class-graph definitions, their raw parameters, native area classes, and exact criterion presence. `server/tools/import_class_cell_group_metadata.py` reproduces this scoped extraction from the full native JSONL graph. No monster books or AI behavior are imported.

Empty eligible population suppresses the runner's own PR notification while preserving retained Qf ownership. A nonempty population with a zero cell count still creates the child context and completes its native notification path. These distinctions follow the original `eYk.c`, `eXR.C`, and `Qe` retention source, rather than a per-spell workaround.
