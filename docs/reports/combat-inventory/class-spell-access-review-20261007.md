# Class spell access lifecycle

The fresh bulk inventory covers all 18 classes, 722 ordinary spell records, 140 structurally class-reachable native family-649 effects, and 107 granted references. Sixteen granted references already belong to the ordinary inventory; 91 are additional class-linked abilities. This reproduces the existing extra-spell set without importing general monster books. The reference closure contains 6,181 effects. Three missing native nodes remain explicit. Structural reachability does not establish that source conditions or events actually execute.

The ordinary inventory uses native class and unlock-level data in `spells.json`; its `available_spells` function is a class/level inventory, not a list of every action a class can acquire in combat. Adding temporary abilities there would erase their state, ownership, and lifetime conditions. Native innates and passives install through common class initialization; family 649 (`eWn`) creates combat-time book objects and shortcuts. Family 193 changes current WP and is not a spell-grant mechanism.

Cra's innate state 3419 structurally grants its beacon abilities and other extra actions. Sacrier's innate state 3702 supplies extra actions whose actual native conditions can depend on level and deck membership. These conditions remain evaluated by the shared native effect and casting producers. No spell ID or class-specific exception was added.

Before this correction, `resolve_owned_spell_action` found a real raw-UID temporary record but rejected its cast whenever `WAKFU_NATIVE_GRANTED_CAST=0`. The resolver now accepts only an actual well-formed grant belonging to the active owned actor, preserving current-turn, control, life, controller-chain and UID checks. Removing the registry entry makes the raw UID inaccessible. Ordinary packed player spell UIDs still require the actual current deck. Native casting criteria, costs, range and usage checks still run after ownership resolution.

The compiler now merges granted-catalog members of the exact class-owned grant closure even when the broad native-grant feature flag is disabled. This does not grant actions or import unrelated monster trees. Actual runtime possession, rather than catalog membership, authorizes casting.

Native `eWn.fMO` tests `fyR.f` by object UID and retains an existing raw-UID object instead of replacing its level. `eWn.bbR` removes that object UID without reference counting. The shared book overlay reproduces this behavior for fresh controlled summon books, including removal of a pre-existing raw action and a subsequent new grant. It retains an explicit tombstone for the removed source object instead of resurrecting the immutable source book. A raw grant removal does not remove a player's packed object.

The player progression book is separate: original `bjo.dsx` reads `bPN.elA`, and `eLo` delegates PLAYER_CHARACTER level queries to `fzj`. Temporary grants are not invented progression entries; absent progression remains -1, and the actual deck execution cap still applies. The immutable original summon/profile book remains the provenance source; the runtime overlay represents only source-proved book operations.

`ProbeNativeSpellGrantRegistry.java` passed 10 checks against the installed original RC methods inherited by fyR, including UID collision, removal, regrant and packed/raw identity. It used a 256 MB offline JVM and loaded no game catalogs. The existing native eWn wire probe checks additional fields for reference, level, bar and slot. These probes are narrower than complete class gameplay.
