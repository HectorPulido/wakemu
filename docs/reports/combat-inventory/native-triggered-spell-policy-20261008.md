# Native family 426 and Wakemu nested spell policy

## Original source boundary

The registered runner is `eYZ`. Its computation evaluates parameter 2 at the runner level when three parameter pairs exist; otherwise `rHe` remains true. The original parameter descriptor identifies this flag as consuming the spell cost. Application evaluates parameter 0 at literal level 1, resolves the bound target's coordinates or the selected cell, and calls `eGj.a(int, aBn, boolean)`. Raw parameter 1 selects actor versus cell ownership. No runner-value calculation or reversal of the triggered gameplay exists in this runner.

The installed original `eGj` hook has an empty body. An exhaustive constant-pool descriptor scan found only the declaration and the `eYZ` caller. Consequently the implementation below is an explicit Wakemu server policy, rather than a recovered original server implementation.

## Shared execution policy

`NativeTriggeredSpellHandler` preserves the original spell reference, coordinates, cost flag and supplied execution context. The factory executes nested roots on the same outer transaction preview and appends its private packet list only after successful completion. Nested casts use their actual active spell container and the shared 1024/1025 lifecycle. Their fresh execution context uses the exact native constructor under the declared server origin policy; it does not replace the incoming parent context.

Owned spell-book levels take precedence. Internal helper abilities absent from that book require a typed descriptor bound to the compiled original family-426 definition and the native casting table. Their evaluation level is the actual caster level capped by the native ability maximum. A parent runner level or arbitrary deck entry supplies no fallback. Unknown books, caster levels or definitions reject explicitly.

When `rHe` is true, the actual native casting table supplies AP, MP and WP costs and conditional cost rules. All three are checked before payment. When false, all three payments are zero. Triggered helper casts use these rules rather than normal user turn/deck eligibility. The current nested factory inherits the outer provider's critical-branch choice; it does not invent an independent original nested critical draw. Repeating the same caster/spell pair or exceeding 32 nested scopes rejects with a diagnosable recursion-policy error.

The factory exposes its actual `Random` owner. `prepare_spell_transaction` checkpoints that owner and restores it on failure, while the existing outer server checkpoint also covers earlier critical draws. Fight state and packets remain inside the uncommitted transaction preview. Retained actor-target runners register their actual record before ordinary lifecycle notifications; removal removes the retained runner without undoing nested spell gameplay. Retained null-cell manager ownership remains unresolved and rejects explicitly.

## Dependency import and verification

The five missing references 7697, 7698, 7699, 8509 and 6849 were exported together from original client classes with a 256 MB JVM. The scoped typed export contains five spell containers, 314 effects and twelve states, without NPC profiles. The generic importer verifies identities and state selection contracts and adds 200 previously missing effects to the compiled runtime. The separate original zero-level casting getter export also completed successfully for all five containers and 200 selected effect closure entries; its generic table integration is being finalized. Positive-level native tables are already present.

Thirteen focused unit tests pass for exact request inputs, cost handling, internal level binding, recursion and RNG rollback. Two actual-factory transaction regressions are staged for isolated validation: successful helper ability 7697 and a mandatory nested-root failure after an RNG draw. Their activation fixture deliberately clears the original runner criterion to isolate execution machinery; it does not certify the original class activation condition. Full class coverage and manual client acceptance remain separate work.
