# Displacement carry flag37

Offline enum bytecode identifies `eVl.rxh` as code37, `DO_NOT_UNCARRY`. An exact owner/name field-consumer scan of the installed client finds one runtime consumer: `eXD.fOQ`. It obtains the displaced `fax`, requires `eHG`, reads `frA()` (carrying another actor), and returns before checking the flag when that relation is empty. With a carrier it may instead execute the native uncarry definition; that producer remains outside the ordinary actor handler.

`ProbeNativeDisplacementUncarryFlag.java` invokes the original method with an explicit `frA=false` proxy. Both definitions, with and without37, perform one carry read and zero flag reads. The probe passes. The shared displacement handler therefore accepts37 for its proven ordinary actor domain, while requiring both physical carry relations to be explicitly empty. Unknown or active carrying authority rejects before mutation; it is never inferred from `is_carried`.
