### Rejected Columnata self-target attempts

Both failures target the Sacrier's own cell `(-23,-143,70)` in the ordinary level-20/200 actual-turn baseline. The ordered tree first completes damage effect **416130 / class 3** against enemy actor `-7` at `(-22,-143,70)`, then effect **416131 / class 1013** attempts armor on that same enemy and fails with `Invalid native armor fight/target`. Its parent is **416129 / class 330**, under root **196997 / class 330**. Both attempts have `source_preserved: true`, so the transaction rolls back and the source fight/resources are not committed. This is a real rejected effect branch, not an ineligible cell or ordinary targeting rejection.

An isolated diagnostic repeated the same normal self-cell cast at levels 20 and 200, changing only the native NPC fixture: the low NPC 5525 level 1 has 12 HP and both attempts reject; the native NPC 3646 level 12 has 84 HP and both prepare successfully, leaving 76 HP/+2 armor at level 20 and 20 HP/+17 armor at level 200. `NativeArmorHandler._calculate` rejects when the fight is not active, there is no current actor, or the target has `hp <= 0`; the cast is at the active Sacrier turn in an active fight, and the higher-HP comparison passes. The evidence therefore points to the level-1 NPC being killed by 416130 before 416131 tries to armor it. The exact native expectation for a later sibling effect after a lethal hit is still unresolved: the server currently rejects the entire preview instead of skipping armor on the dead target. Record this as a concrete root-failure branch for review, not as proof that Columnata's normal living-target result fails or that the native behavior should apply armor to a corpse.
