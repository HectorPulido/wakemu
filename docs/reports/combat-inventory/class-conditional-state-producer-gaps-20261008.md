The current precondition builder records `innate_owner_breeds` only when a required state is itself a direct innate seed. It therefore omits transitive innate **effect** producers. Joining each original family304 state-reference effect with `innate_dependency_components.effect` recovers the ownership evidence in the table. The source index must retain both direct seed ownership and transitive producer ownership as different facts.

A second general gap is fixture qualification:6752,7647 and9309 already have source spell callers, but their extra-book caller and conditional request can leave the active deck empty. An empty legal deck is not proof that no owned grant can exist after production Ready. Future execution must inspect actual registered grants and reject unavailable callers normally; manually granting them would bypass the contract.

Bulk recovery should traverse retained innate subscriptions and ancestor guards as well as ordinary spell edges. The extraction must preserve trigger type, source/caster/target identity, class scope, ordering, current states, counters, deck conditions and geometric populations. It should seed native state lookup from every class casting AST reference and export only that scoped dependency closure. Existing source loops are candidate paths, not proofs of reachability or unreachability.
