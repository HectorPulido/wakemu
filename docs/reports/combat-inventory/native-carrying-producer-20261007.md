## Native shared geometry

Original `eGj.a(eHH)` first applies `b(eHH)`: distinct recipient, neither participant already carrying/carried, recipient `c(eHG)` acceptance, and the exact signed-height disjunction using `eGH.bcK()/2`. The disjunction is preserved literally; no proximity rule is added.

On success, native code sets carrier `pGV`, calls carried `a(eHG)` to set reciprocal `pGW` and `QI.a(QK,false)`, then moves the carried coordinates to the carrier and invokes `bpP`. Carried `eGj.a(IIS)` explicitly skips `QI.a(QK,x,y)` while `buX` is true. Its reserved QK slot remains present but unindexed. Carrier movement recursively updates carried coordinates. Direction mutation `eGj.a(aAS)` rotates the carried direction by the carrier's direction delta.

Release `R(aBn)` updates carried coordinates while still carried, calls `dda()` to clear `pGW` and enable QI indexing, then clears carrier `pGV`. If the destination differs and property `ffe.sev` is absent, it first turns the carrier toward the destination, propagating the direction delta. Neither carry nor throw has a custom runner removal that reverses the relationship. Removing a runner must not invent an automatic release.

`big` overrides add client animation callbacks. Controller identity remains independently owned by `fcb.rRN/fdt`: `big.dpr -> dnH -> eGj.c -> fcb.aV`. Carrying alone does not register a control transition.

## Implemented shared producer

`combat_carrying.py` records a frozen reciprocal pair with current coordinates, both directions and source UID. Raw relationship attributes and stale coordinates/directions cannot satisfy the producer. Carrying prepares the complete QI change before publishing actor state; release likewise prepares the index transition before clearing relations. Reserved-slot movement does not insert QL bytes or alter insertion history.

`current_registry` accepts only these verified pairs and checks carried slots remain unindexed. `move_registered_actor` updates carrier and carried coordinates together. Ordinary actor authority consumes the verified carried/carrying predicates while preserving its independent master/controller guards. Shared direction call-site integration is owned by the casting agent.
