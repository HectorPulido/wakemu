## Console commands: exact support and limits

The implementation is [`test_console.py`](../../../server/wakfu_server/maps/test_console.py) and [`command_permissions.py`](../../../server/wakfu_server/storage/command_permissions.py).

- `!nivel 200` is canonical; `!level 200` is its supported alias. It permanently raises the selected character and cannot lower a level. It updates character level/progression and reinitializes health. Use a disposable character below level 200; do not use a higher-level account character expecting a temporary level change.
- `!mob PROFILE LEVEL COUNT` is canonical; `!monster PROFILE LEVEL COUNT` is an alias. `COUNT` must be 1–8 and the profile/level must resolve in native monster data. It spawns a group using reachable, free native map cells from the character's current origin; placement and LOS therefore depend on the actual map and nearby occupants. The local server only supplies the test-group provider when `WAKFU_ENABLE_COMBAT_TEST=1`. The command requires instance 0 and is explicitly rejected in an active dungeon room. Finish or surrender the current group before creating another.
- Both commands use the database-backed command allowlist. Accounts with admin permission can execute them; otherwise the canonical command must be included in `player_allowed_commands`. The default player allowlist is only `!ayuda` and `!pos`. The guides do not authorize changing that policy or a running service's environment. If either command is unavailable, use an already permitted ordinary PvM/friendly challenge and do not claim the command was tested.
- `!nivel` and `!mob` are the only console conveniences assumed by these batteries. Decks/passives are selected through the normal client UI. There is no documented manual command here for adding a spell, state, resource, summon, bomb, portal, dial or class grant.

For short opening/KO checks only, the existing examples `!mob 4 8 1` and `!mob 4 8 3` use native profile 4, level 8 and a count of one or three. Such low-level enemies may die before delayed, passive or multi-turn effects occur. Use an ordinary durable encounter or consenting player for those branches. `docker compose logs --since 10m world` is an existing local observer command; redact private log data before sharing.
