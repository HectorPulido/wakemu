# Shared native faU deposit lifecycle

## Executed native proof

`ProbeNativeDepositLifecycle` loads installed aKa definitions through bcN and selects actual faU instances. All four installed ENUTROF_DEPOSIT prototypes pass actual construction and cloning: type12, PL/container3, actual parameter0 deposit grade, Qq fresh guards, null Qf where property12 is absent, non-obstacle behavior, native zero radius/height and registered point geometry.

faU inherits faV and Qq. Its `aQc` initialization is a no-op, `e(amP)` returns true, `c(amP)` supplies the actual non-null recipient coordinates, and `d(amP)` returns that same recipient for cleanup. Null recipients return no coordinates or cleanup target. These contracts differ from HOUR owner-only activation. Grade `fTu` is Java float-to-int conversion of Qr.bdh parameter0, independent of the running area level. The four installed grades are captured from that native field.

## Implementation

The shared `combat_area_contracts` registry names the six verified faV subclasses. ENUTROF_DEPOSIT uses faU; it is not relabeled as a glyph. Creation captures grade and provenance before registration. Queries and registered PV resolution reject missing or altered grade authority. Existing generic faV/Qq callback, charge, owner affiliation, area PL, removal and geometry machinery applies. The deposit receives no fabricated fighter resources, turns, QI obstacle byte or Qf.

Auxiliary domains now consume the same verified subtype registry: original-controller eHg queries, actual triggering area containers, casting area targets, retained area removal, checkpoint state-manager identity and the legacy non-obstacle summon preflight. The existing type12 own-deposit predicate can therefore consume actual registered records. Actual owner PV identity remains distinct from controller identity.

`eOC` extends `eOz` and changes only the required area type to12. Its inherited optional boolean therefore selects only the area center for a cell argument when true. The previous helper inverted that native branch and excluded the center. The shared deposit predicate now follows the actual `aBn.Y` bytecode branch, including XY-only center comparison. Non-cell target forms retain their native independent behavior.

## Validation and limits

Four new tests cover all installed deposits at creation, query/owner/controller/removal behavior, malformed grade provenance and actual Qq triggering-container namespace. Syntax checks pass for the changed modules. Python unit execution is delegated to the shared validation worker using a private snapshot; no live service was touched.

The native Java proof establishes the subtype primitives, not a complete Enutrof gameplay sequence. Entry masks include the still-unrecovered external area event10006 producer. Existing server turn-start policy and actual movement/source deliveries remain explicitly identified in the shared area report. WALL/fbd has a distinct HP, Qf, obstacle and channel6 constructor and is handled separately.
