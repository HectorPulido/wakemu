# Character-copy descriptor and appearance

Family1002 uses its own `eZo` additional-data codec. The new shared codec serializes original `vJ`, a present `vK/up`, absent `vM`, and the native optional spell-level trailer. It does not reuse a307 or324 descriptor.

`eHI.a(vJ)` supplies `up.ade` percentage, `up.adf` source `bwX()`, `up.Su` actual dS appearance, `up.adg` literal1, ordered yC spell rows, ordered tA raw characteristics and ordered don category rows. Original yy rows are UID:int64/reference:int32/level:int16. Original ffk assigns tB fields identifier:int8/current:int32/minimum:int32/maximum:int32/percentage:int32. uq rows are category:int8/reference:int32. Source order is retained. Empty collections require explicit typed tuples.

`eZo.as` appends a byte count and reference:int32/level:int32 for every nonzero-level copied spell when actual `faB.fTc()` is true. The count narrows as Java byte; rows retain encounter order. The application packet uses the shared native effect envelope and family1002 header, preserving created actor identity separately from runner amount.

The connected appearance provider reads the authoritative owned character dictionary and `wire.appearance_section(...)[2:]`. For an attested live source record, model and ordered categories are required. For a fresh ordinary eHP source, it requires verified native actor type0, eHP identity and the actual ordinary entity encoder's pO count0. Original bjy.zm clears/initializes igU and iterates pO.TP; therefore that transmitted empty population produces an empty don map. Model selection is separate: bjo.bwX uses a nonzero pGT override or cgI, while dtd derives cgI through bhe.b(breed, signed-byte sex, signed-byte clothIndex). The supplied model callback must use the authoritative original breed-model catalog. Breed ID is never substituted for model ID.

Original `ExportNativeClassCopyAppearance` now publishes `server/protocol/native-class-copy-appearance.json`: all18 actual class seeds from the innate catalog, two sexes and256 signed cloth operands, totaling9216 original model selections. It invokes the original aKf loader and private aZL graphics producer, then bhe.b directly. Client jar, selected bdata bucket and class-seed hashes are recorded. The default connected appearance callback consumes this published model table; seed/population validation prevents incomplete tables from silently falling back.

Validation: original `ProbeNativeCharacterCopyCodec` at128MB produced two exact vJ/vK/up byte streams, covering nonempty appearance/book/stats/categories and signed boundary/null-name/empty-collection cases. Focused Python tests cover source identity, model callback operands, published18-class completeness and eZo trailer behavior. All9216 published model selections were checked through the runtime loader. The live constructor/book provider is coordinated with the character-copy builder owner; codec parity alone is not a full1002 gameplay acceptance result. No services were modified or restarted.
