# Microbot path and callback contracts

Original `fdq.j(QI)` configures `Sn.a(6,1,4)`, binds the actual QI environment, sets `QI.bf(true)`, builds both axis groups, and resets the flag plus `Sn.bal()` on success and exception. `Sn.c(aBn,aBn)` calls `Sn.a(...,false)`. Its physical-column cache reads inherited `VE.aO` and `VB.a`; QI has no override for `aO`. The optional `QI.Z` mask branch is skipped for this call. Native dynamic QK occupants therefore do not become physical-column obstacles in this rail predicate; actual physical blocked surfaces and height/jump transitions remain effective.

`combat_microbot_path.microbot_path_projection(fight)` binds complete `current_registry` authority, published native physical columns and published mask-selected QI surfaces for the same actual map. Its methods `segment_is_passable(start,end)` and `surface_z(x,y)` provide the native rail queries to the shared network producer. This is a pure projection of the temporary query: it does not mutate a fight flag or leak obstacle exclusions to ordinary movement. `QI.X` uses the original mask's low six surface-index bits, not a guessed map height.

Three focused unit tests pass: occupied QK cells do not alter the rail result or QI checkpoint; physical blockers and jump four remain enforced; cell altitude comes from the actual QI.X projection. These tests isolate provider behavior and do not certify microbot creation or class completion.

The native `fdn.a` callback receives added segments, removed segments, added cells and removed cells. Original `fdp` initializes that callback to null. An exhaustive constant-pool scan of `wakfu-client.jar` found no caller to `fdp.a(fdn)`, and only `fdp`, `fdo` and `fdq` reference an `fdn` descriptor. No installed client callback consumer or lambda origin is established. Segment order is native; Java HashSet cell iteration remains separate from unordered membership. A future non-null callback must preserve that distinction and must not claim an original delivery packet or rail movement-cost rule without its own source contract.

The network producer and area registration are owned by the shared `combat_microbot_network` integration. This review introduces no new wire message, AI behavior, database change or service restart.
