# AI service optimization audit — 2026-10-10

## Scope and conclusion

Read-only audit of the current AI planner, native oracle, content transport and live decision telemetry. No gameplay code, budgets, authority checks or deployments changed as part of this audit. The main remaining measured cost is repeated native preview work during a decision, rather than HTTP startup or one intrinsically slow NPC metadata document. Optimizing this path requires preserving complete encounter authority and spell behavior.

Evidence: `.runtime/local/logs/game-server.jsonl`, 58 unique `combat_monster_tactical_action` decisions in the 16:00–17:59 UTC window. Precommit/postcommit duplicates were consolidated by boot, fight, actor, turn and request identity. These observations describe that window, not every possible encounter.

## Timing interpretation and previous incidents

`native/native_turn.py:119` and `:188` calculate `elapsedMs` from the turn start. A late end-turn event with 4,683.8 ms elapsed had a current search stage of 1,712.4 ms; it was not one 4.68-second search. Nested timings are inclusive: preview execution is inside cast/move query timing, and repertoire prerequisites are inside repertoire timing. Their totals must not be added together.

The older 07:10 UTC fight 150 incident had approximately 15.55 seconds of thread CPU in repertoire metadata preparation; warm preparation subsequently took approximately 10 ms. An isolated actual-metadata encode measured approximately 7–12 ms, so document size alone did not explain the incident. Allocation/garbage collection was a hypothesis, not an established cause from those measurements. See `AI-SEARCH-AUDIT-20261010.md` and `LIVE-SLOW-COMBAT-20261010-0710.md` for the earlier evidence. No corresponding 15–30-second decision outlier was identified in this audit's later window; this does not establish that the original cause can never recur.

The NPC casting-root coverage issue was a correctness dependency, not a search tuning opportunity. The staged complete root export preserved all prior class records and added authoritative NPC roots, including Wonejo spell 7962 root 361119. See `NPC-CASTING-ROOT-COVERAGE-20261010.md`. Never make unsupported spells eligible merely to shorten rejected candidate searches.

This audit does not relax those guards or claim they are harmless.
