Distribución mínima del launcher · macOS

Artefacto: .runtime/distribution/wakfu-mini-launcher.zip.
Recrear: python3 client/tools/package-mini-launcher.py.
La carpeta mini-launcher se coloca dentro de Wakfu, junto a lib/, contents/,
jre/, classpath y config.properties. Launch.command abre la UI del launcher
existente con config.json. El cliente original no se modifica.

Contenido enumerado explícitamente: launcher UI, configuración, runner Python y
bash, puente Thrift Python, helper de rutas, README, manifest SHA256, agentes
propios network-guard y desktop-fix compilados, y sus fuentes Java.
No se copian wakfu_server, CaptureAgent, sniffer, cliente/lib, contents, Java del
cliente, perfiles reales, tokens, contraseñas, SQLite ni capturas. El ZIP contiene
14 archivos y pesa aproximadamente 22 KB. El manifiesto permite verificar cada
archivo. Fechas, orden, modos y compresión del ZIP/JAR son deterministas.

Runner: detecta cliente instalado en el padre; admite también padre/client o
Contents/Resources si contienen los archivos exigidos. Perfil main reside en
mini-launcher/profiles; otros perfiles en profiles/instances/<nombre>. Datos
mutables/config.properties están aislados; archivos originales se enlazan.
No importa módulos del servidor ni requiere la estructura del repositorio.

config.json configura API y servidor por IPv4 numérica, puertos de dispatcher,
mundo, chat y HTTP. API debe usar exactamente server_host. Guardia Java bloquea
DNS ajeno y sockets ajenos; sandbox-exec cubre sockets nativos. Para servidor
remoto se permiten únicamente los puertos configurados del host. Loopback se
permite para puente efímero. El servidor debe anunciar su dirección de mundo
correcta: el launcher no reescribe respuestas del servidor ni sustituye 127.0.0.1
anunciado por el servidor actual.

Requisitos de ejecución: macOS con sandbox-exec, Python 3 con Tkinter y cliente
actual con Java 21. JDK se usa solamente para construir el paquete. Windows y
Linux no están implementados. No incluye actualizador ni elimina cuarentena.
Las transformaciones desktop dependen de clases de la versión de Wakfu actual.

Validación: ZIP extraído fuera del repo; runner --check detectó instalación real
y ejecutó agente con Java21 del cliente dentro de sandbox-exec. Test de guardia
rechazó ankama.com, wakfu.com y socket/DNS externo sin hacer peticiones. No abrió
el juego. Seis pruebas adicionales verifican detección, perfiles/rutas, rechazo
de hostname/API dispares, IP remota configurable, reproducibilidad de ZIP y
ausencia de dependencias/archivos privados. Dos construcciones iniciales fueron
idénticas byte por byte. Login/selección/personaje con este ZIP no se ha probado
con GUI todavía; el puente deriva del ya usado, sin capturador.
