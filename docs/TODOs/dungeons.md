# Dungeon, rift and Ultimate Boss testing checklist

156 catalog entries: 126 dungeons/other encounters, 5 legacy/seasonal encounters, 10 dimensional rifts and 15 Ultimate Boss entries (including Neo variants). Each rated section is sorted by native entry level.

Sections: [Dungeons](#dungeons-and-other-encounters) · [Grandmeow and seasonal encounters](#legacy-and-seasonal-encounters) · [Dimensional rifts](#dimensional-rifts) · [Ultimate Bosses](#ultimate-bosses).

Copy the `!tp map x y z` command into chat to reach the entrance, then interact with it to enter normally. The command requires teleport permission. Unknown entrances have no invented command.

For each entry: check access, connected combat areas, room progression or waves, boss, rewards and exit. Tick only when working; append problems after **Notes:**. Special-mechanic checks come from archived guides and may differ by client version. A listed entrance does not guarantee that encounter is enabled.
