ARRANQUE LOCAL AISLADO DE WAKFU

El servidor del experimento y el puente que simula al launcher están escritos
en Python, usando la biblioteca estándar. WakBox se utiliza como referencia.
Los agentes Java son auxiliares del cliente: aislamiento de DNS/sockets,
captura y una corrección de escritorio de macOS; no implementan el servidor.

Arranque desde la carpeta del experimento, en dos terminales:
  ./local-server.sh
  ./local-client.sh

Comprobar las barreras de red sin abrir el cliente:
  ./local-client.sh --check

Ver la ventana o su captura:
  python3 inspect-client.py --local state
  python3 inspect-client.py --local screen
Leer coordenadas reales del personaje:
  python3 inspect-client.py --local position

DESTINOS Y AISLAMIENTO
Dispatcher TLS: 127.0.0.1:15558.
Servicios HTTP configurados: 127.0.0.1:18080 (aún no implementados).
Chat externo configurado: 127.0.0.1:16337 (aún no implementado).
API de cuentas: 127.0.0.1:18081.
Puente del launcher: puerto efímero de 127.0.0.1, token local de un solo uso.

El perfil .runtime/local/client tiene config.properties propio y preferencias
y caché independientes. Los recursos del cliente se comparten mediante enlaces.
La configuración original y los tokens reales no se usan para este arranque.

sandbox-exec restringe las conexiones del proceso y sus hijos a loopback,
incluidos sockets nativos; también deniega servicios Mach de resolución DNS.
El agente LocalNetworkGuard bloquea en Java la resolución de nombres externos
y las conexiones externas, e impide quitar esa barrera durante la ejecución.
Las pruebas previas exigen rechazo por permisos de una IP externa y rechazo
de DNS a dominios de Ankama, además de conexión satisfactoria a localhost.
El arranque se detiene si falla alguna prueba o no se puede aplicar el sandbox.

Este bloqueo pertenece a los procesos del experimento. Otras aplicaciones de
macOS conservan su configuración de red. Al cerrar estos procesos, desaparece
su bloqueo; no hay modificaciones que revertir en /etc/hosts ni en el DNS global.

AJUSTE DE MACOS
El cliente puede abortar al llamar desde AWT a showMenuAndDock, una función
nativa que modifica el menú de macOS fuera de su hilo principal. El agente
LocalDesktopFix omite esa llamada en memoria para este perfil de ventana.
No modifica el JAR original ni el protocolo.
El mismo agente omite las llamadas del helper de telemetría cbW en este perfil:
sin su contexto remoto habitual, el helper lanzaba un NullPointerException al
procesar el resultado de login, interrumpiendo la entrada a personajes.
